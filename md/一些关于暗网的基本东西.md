# 1.首先需要tor
## 安装[Tor](https://www.torproject.org/)

### 通过官方安装（不行就试试flatpak）
```bsah
sudo apt update
sudo apt install torbrowser-launcher
```

```bash
sudo pacman -S tor
```
# 启用并启动 Tor 服务
```bash
sudo systemctl enable tor
sudo systemctl start tor
```
## 检查服务状态
```bash
systemctl status tor
```
