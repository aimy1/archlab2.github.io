# 安装依赖环境

### [Node.js](https://nodejs.org/zh-cn) 和  [Git](https://git-scm.com/downloads)
---
## 安装 Hexo CLI

```bash
npm install -g hexo-cli
```

如遇 npm 版本过低提示：，运行命令安装最新版本(manjaro不用管)
```bash
npm install -g npm@latest
```

## 初始化 Hexo 项目

```bash
mkdir hexo（建立一个叫hexo的文件）
cd hexo（进入这个文件夹下）
hexo init（初始化）
npm install
```

## 启动本地服务器浏览器查看效果

```bash
hexo server
```

## 初始化 Git 仓库并提交代码
先设置 Git 用户信息（存在差异）

```bash
git config --global user.name "你的名字"
git config --global user.email "你的邮箱"
```
## 确认设置成功
```bash
git config --global --list
```

## 初始化仓库（自行配置）

```bash
echo "# aa" >> README.md
git init
git add .    [git add README.md]
git commit -m "first commit"    [git commit -m "Initial commit"]
git branch -M main
git remote add origin https://github.com/aimy1/aa.git
git push -u origin main
```

## 推送代码到 GitHub
登录 GitHub 手动创建一个新仓库
1st登录 GitHub，点击页面右上角的 + 按钮，选择 New repository（新建仓库）。
2nd在 Repository name（仓库名称）框中，填写你的仓库名称（例如：hexo）。
3rd在 Description（可选描述）框中，可以添加仓库的简短描述（如：“我的 Hexo 博客”）。
4th选择 Public（公开）或 Private（私有），通常选择 Public 让其他人也可以访问你的仓库。
5th其他设置可以保持默认即可，点击 Create repository（创建仓库）按钮。

## 添加远程地址并推送代码
创建仓库后，GitHub 会显示仓库的主页，找到并复制仓库地址，形如：
https://github.com/your-username/hexo.git
在终端中，执行以下命令将你的 Hexo 项目推送到 GitHub：
git remote add origin https://github.com/your-username/hexo.git
git branch -M main  # 若默认是 master，可改为 main
git push -u origin main
其中，your-username 是你的 GitHub 用户名，hexo 是你的仓库名称。
如果 GitHub 提示需要验证你的 GitHub 账号，可以通过输入用户名和个人访问令牌（Token）进行认证。

##  使用 Cloudflare Pages 自动部署
创建 Pages 项目
1.登陆 [Cloudflare](https://dash.cloudflare.com/) 后台 → 选择 Pages
2.点击 创建项目
3.连接 GitHub，选择所有仓库或指定仓库授权
4.授权成功后，选择你的 Hexo 仓库开始配置

## 构建设置
构建命令
```bash
npx hexo generate
```
发布目录
```bash
public
```
框架预设：选 None

## 7. 配置自定义域名（可选）
自动解析 (限定顶级域名托管于 Cloudflare)
1.点击 “设置自定义域名”
2.输入你的域名，Cloudflare 会自动生成 DNS 解析
3.等待几分钟，域名生效

手动解析（域名未托管CF或为子域名）
1.选择“我将手动添加 DNS 记录”
2.根据提示，到域名 DNS 服务商处添加 CNAME 记录
3.点击“检查 DNS 记录”，等待解析生效
