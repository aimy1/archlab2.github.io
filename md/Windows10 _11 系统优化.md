# 系统开启卓越性能的方法+代码
首先在搜索栏里找到：Windows PowerShell

找到后以管理员权限打开它

然后输入以下代码回车确认即可！

Powershell命令代码：
```bash
powercfg -duplicatescheme e9a42b02-d5df-448d-aa00-03f14749eb61
```
然后在控制面板>硬件和声音>电源选项>选择电源计划。去选择[卓越性能]
